# Bernardo Bergamini

I build AI products that run in production. I'm a co-founder and the tech lead of Apex AI, and a Computer Science student at Unisinos, in Porto Alegre, Brazil.

## What I'm building

**Apex AI** is a multi-tenant SaaS for vehicle dealerships. Leads arrive from WhatsApp, Instagram, Meta ads and the website. An AI agent handles the first conversation, qualifies the customer and hands off to a salesperson with a summary.

The source is private, so I wrote up the product and the engineering decisions in [apex-ai-case](https://github.com/bndsiqueira/apex-ai-case).
